> **「歌ってみたの録音トラックに混ざった唾液の『ペチャッ』『クチャッ』というリップノイズを綺麗に消したい…」**  
> **「DAWの鉛筆ツールで1箇所ずつ波形を手描き修正するのは何時間もかかって気が狂いそう…」**  
> **「高額なプラグインを買う余裕はないけれど、フリーのノイズ除去をかけると歌声がモコモコに劣化してしまう…」**

『ClickRepair GUI』は、「歌ってみた」のMIX師・ボーカリスト・声優・ASMR配信者のために開発された、**音声の正常な高域・音質を100%原音維持したまま、唾液のリップノイズや突発クリックノイズの極小点だけを局所三次スプライン補間（Cubic Spline）で外科手術のように滑らかに再接続・修復するWindows専用ポータブルGUIツール**です。

インストール不要。解凍してダブルクリックするだけですぐにお使いいただけます。

## 💡 このツールで解決できるお悩み

- **地獄の手描き修正・ハサミ作業からの解放**: 何十箇所もあるリップノイズをDAW上で探して1つずつ手描き修正・クロスフェードする膨大な手作業（1〜2時間）を、ワンクリックで一瞬で終わらせます。
- **歌声の音質劣化が絶対に起きない（100%原音維持）**: 全体にフィルターやEQをかける従来のノイズ除去ソフトと異なり、クリックが存在する「わずか0.5ミリ秒の極小点」だけを修復するため、99.9%の健全な波形は1サンプルも変化せず完全なビットパーフェクト原音を保ちます。
- **サ行「s」などの子音が削れない（子音保護フィルター）**: 高域の摩擦音やアタック子音をノイズと誤判定して削らない「子音保護フィルター（Consonant Guard）」を標準搭載。
- **「取れたノイズの音だけ」を耳で確認できる安心感**: 「除去ノイズ単体試聴（Delta Listen）」により、削り落とされた成分だけを再生可能。「歌声が削れておらず、唾液音やクリックだけが綺麗に取れていること」をご自身の耳で100%確認できます。

## 🛠️ 主な機能・特徴

1. **用途別ワンクリックプリセット完備**
   - **歌ってみた・ボーカル**: 標準リップノイズ除去 / 唾液音特化（2kHz以上フォーカス）
   - **ナレーション・朗読・ASMR**: 微細マウスノイズ徹底除去 / 高感度＆2パス修復
   - **突発パルス・静電気クリック**: マイク・機材ノイズ修復 / 全帯域スキャン
   - **レコード・針飛び・アナログノイズ**: 短尺クリック修復
   - **カスタム**: 感度や補間パラメータを自由に設定
2. **局所三次スプライン補間（Surgical Cubic Spline Repair）**
   - 不連続な段差が生じた極小サンプル区間を、前後の波形の傾きから数学的に最も滑らかな曲線で再接続。耳で聞いても修復跡が全くわからないプロクオリティを実現。
3. **除去ノイズ単体試聴（Delta Listen）＆ 差分WAV書き出し**
   - 画面上で「元音声 - 補正後音声」の差分ノイズを再生可能。さらにオプションで差分WAV（`*_removed_clicks_only.wav`）をZIPに同時出力可能。
4. **案件納品用 証明CSV ＆ DAW用マーカーCSV自動出力**
   - 修復クリック総数や最大ノイズ振幅をまとめたレポートCSVに加え、修復された全クリックのタイムコード一覧（分:秒.ミリ秒）を記載したマーカーCSVをZIP同梱。DAWにマーカーとしてインポート可能です。
5. **完全ローカル＆文字化け永久防止設計**
   - 外部通信は一切行わず、元ファイルを上書きしない非破壊設計。ZIP内ファイル名は100% ASCII準拠でWindows展開時も文字化けしません。

## 🚀 使い方（3ステップで完了）

1. **用途プリセットの選択**
   - 「1. 用途プリセットの選択」から目的のスタイル（例: 歌ってみた・ボーカル）を選択します。
2. **音声ファイルの選択**
   - 「2. 対象音声ファイルの選択」に対象のWAV/MP3/FLAC音声をドラッグ＆ドロップします。
3. **実行と仕上がり確認**
   - 「🚀 クリック・リップノイズ除去を実行」をクリックします。
   - 処理完了後、プレビュー試聴や「除去されたノイズ成分のみ（Delta Listen）」で歌声が削れていないか確認し、「📦 修復済みWAV ＆ 納品レポートを一括ダウンロード（ZIP）」をクリックして保存します。
